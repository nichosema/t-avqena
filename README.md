# Tavqena

One-page AI customer conversation opportunity intelligence.

Paste a customer conversation -> analyze -> opportunity signals, priority, friction, next action and a ready-to-copy response.

## Run
npm install
copy .env.example to .env.local
add OPENAI_API_KEY
npm run dev

## Deploy
Use GitHub + Vercel. Add OPENAI_API_KEY in Vercel Environment Variables.

The MVP is intentionally one page.
